Privacy Policy

How Leaf handles your data.

Details about the limited analytics Leaf collects and how your reading data is protected.

The short version

Your books stay yours.

  • Leaf never sends book files or book text to analytics services.
  • Book titles and author names stay out of analytics.
  • You can turn off analytics at any time in Settings.

Last updated July 22, 2026

Leaf takes your privacy very seriously.

Leaf uses PostHog to collect limited app usage analytics, such as feature usage, aggregate reading activity, and basic app and device information. Events may include a pseudonymous Leaf analytics identifier and a source label indicating whether it came from iCloud or this app installation.

When iCloud Sync is enabled and Leaf can validate the current iCloud account, Leaf deterministically derives the identifier from Leaf's app-specific CloudKit user record so events from devices using that account can be associated. Leaf never stores or sends the raw CloudKit record identifier. Leaf stores the derived identifier locally with Apple's opaque iCloud account token so it can reuse a cached identifier only for the matching account; that token is never sent to PostHog.

During a temporary CloudKit failure, Leaf reuses only a cached identifier validated for that account; without one, events omit Leaf's identity fields until CloudKit resolves. When iCloud Sync is off or CloudKit reports no authenticated account, Leaf uses a random identifier stored locally in the app's preferences. PostHog also uses its own randomly generated app-installation identifier to process analytics events. Leaf does not use advertising or hardware identifiers.

Book-related events include an opaque library book identifier so activity for the same synced book can be associated across devices. They may also include structural metadata already stored by Leaf, such as file size, position count, language, publication year, whether basic metadata or a cover is present, and the total number of books in the library after an import or deletion. Analytics events do not include book titles, author names, Source names, file paths, filenames, file hashes, source URLs, iCloud account names, or email addresses. They also do not include a book's exact reading location.

You can disable this collection at any time using the Share Analytics toggle in Settings. Turning it off stops future analytics collection; locally stored identifiers may remain so Leaf can reuse them if analytics is enabled again. You can read PostHog's privacy policy for more information about its practices.

If you have opted into allowing Apple to share information with developers, we receive some anonymous analytics from Apple.

Leaf does not sell or rent your data. The analytics information collected is used only to improve the app. Leaf does not send book files, book text, or descriptive library fields such as titles and author names to analytics services.
